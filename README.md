1) Выберите фильм и добавьте его в библиотеку

## Общая информация
- Приложение: Hinter (каталог) 1.0
- Тип проблемы: Зависание приложения
- Приоритет: Средний
- Устройства: Apple iPhone XR
- Платформы и версии ОС: iOS, iOS 15
## Шаги воспроизведения
1) Добавьте сериал в библиотеку
2) Отметьте его как просмотренный
3) Зайдите на страницу сериала из блока «просмотренные»
4) Вернитесь на главную страницу
## Фактический результат
После выхода со страницы сериала из блока «просмотренные» и возвращения на главную страницу, приложение зависает и не листается вниз
## Ожидаемый результат
Приложение работает и страница листается
