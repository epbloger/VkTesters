| **Устройство** | Apple iPhone XR |
| **Платформа / ОС** | iOS / iOS 15 |

### 🔁 Шаги воспроизведения
1. Откройте приложение.
2. Нажмите на кнопку **«Другие игры»**.

## 🐛 Баг 3 — Кнопка «В библиотеку» появляется на фильме, который уже добавлен

| Параметр | Значение |
|---|---|
| **Приложение** | Hinter (каталог) 1.0 |
| **Тип проблемы** | Косметическое несоответствие |
| **Приоритет** | 🟡 Средний |
| **Устройство** | Apple iPhone XR |
| **Платформа / ОС** | iOS / iOS 15 |

### 🔁 Шаги воспроизведения
1. Выберите фильм и добавьте его в библиотеку.
2. Зайдите в библиотеку и нажмите на этот фильм.
3. Нажмите на любого актёра.
4. Выйдите из информации об актёре.

### ❌ Фактический результат
После выхода из карточки актёра кнопка **«В библиотеку»** снова появляется, хотя фильм уже добавлен.

### ✅ Ожидаемый результат
Кнопка **не появляется**, так как фильм уже находится в библиотеке.

## 🐛 Баг 4 — Приложение зависает после выхода из «просмотренного» сериала

| Параметр | Значение |
|---|---|
| **Приложение** | Hinter (каталог) 1.0 |
| **Тип проблемы** | Зависание приложения |
| **Приоритет** | 🟡 Средний |
| **Устройство** | Apple iPhone XR |
| **Платформа / ОС** | iOS / iOS 15 |

### 🔁 Шаги воспроизведения
1. Добавьте сериал в библиотеку.
2. Отметьте его как **«просмотренный»**.
3. Зайдите на страницу сериала из блока **«Просмотренные»**.
4. Вернитесь на главную страницу.

### ❌ Фактический результат
После выхода со страницы сериала из блока «Просмотренные» и возвращения на главную страницу приложение **зависает** — страница не листается вниз.

### ✅ Ожидаемый результат
Приложение работает корректно, страница листается.
